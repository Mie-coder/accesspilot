## 6. 中文简历候选（正式简历未修改）

以下表述只引用已验证的产品行为；是否采用、如何排序和是否加入个人数据，须由用户另行确认：

1. 设计并实现 AccessPilot 企业权限申请 Agent v1.1，建立服务端固定身份与独立 Demo 控制面，隔离角色模拟、故障注入和模型预算。
2. 构建自然语言权限实体解析链路：从当前身份资格目录生成候选，经稳定编码/受控别名解析与服务端重新校验后写入草稿，覆盖唯一、歧义、无匹配和确认失效场景。
3. 将对话链路升级为当前轮增量 SSE 与 Workspace 可恢复事件流，支持游标重连、取消、`turn.interrupted`、刷新恢复和唯一终态。
4. 基于 RAG 构建政策证据卡与三态回答，并用确定性规则阻断自审批及复合提示词、密钥、身份覆盖和未知工具参数攻击。
5. 用类型化业务卡片和事实时间线呈现权限五态、申请审批开通/恢复状态，配套 10 个固定评测场景、30 个案例和多视口质量门禁。
