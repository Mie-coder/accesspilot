# ADR-0001：采用受控双 Agent 架构

## 状态

已接受

## 背景

AccessPilot 既需要通过多轮对话补全访问申请，也需要根据政策判断申请风险。如果让一个 Agent 同时负责业务操作和风险判断，容易出现职责混乱、越权修改和难以审计的问题。

## 决策

系统采用“主 Agent + 风险审查 Agent”的受控双 Agent 架构：

- 主 Agent 负责理解用户意图、补全申请字段、查询员工和权限目录、调用业务工具。
- 风险审查 Agent 只读取结构化申请和政策条款，输出 `RiskReview`。
- 风险审查 Agent 不得修改申请、审批或授权数据。
- 所有状态变更仍由服务端状态机和确认守卫执行，不能只依赖提示词约束。

## 结果与影响

该设计使两个 Agent 的输入、输出和权限边界清晰，便于单独测试风险判断，也便于审计每次政策引用。代价是需要编排两个 Agent，并维护额外的结构化结果和错误处理。
