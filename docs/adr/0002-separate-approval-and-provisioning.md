# ADR-0002：审批与权限开通分离建模

## 状态

已接受

## 背景

企业流程中，经理和数据所有者批准申请后，实际权限开通仍可能因为下游系统超时、网络错误或重复请求而失败。若把审批通过直接视为权限已生效，就无法准确表达失败和恢复过程。

## 决策

系统将审批和权限开通建模为两个阶段：

- `Approval Case` 记录经理、数据所有者等人工审批步骤。
- `Access Grant` 只记录实际成功开通的权限。
- 审批通过后进入 `provisioning` 阶段，再调用权限开通器。
- 开通失败必须保留失败状态和审计事件。
- 重试必须使用幂等键，确保同一申请不会产生重复授权。

## 结果与影响

该设计可以准确区分“流程批准”和“权限已开通”，支持超时恢复、幂等重试和完整审计。代价是需要额外的状态字段、开通结果和错误处理逻辑，但系统可靠性和可解释性更高。
