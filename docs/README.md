- `adr/`：已经确认的架构决策及其理由。
- `architecture/`：系统流程、数据模型与边界说明。
- `design/`：界面设计语言与交互原则。
- `plans/`：产品级实施计划。
- `product/`：已确认的产品定位、角色、功能模块和完整体验边界。

- `specs/`：版本需求、范围和验收标准。
