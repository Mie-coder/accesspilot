# AccessPilot 产品化 Agent v1.1 Spec

**状态：** 产品方向已确认，T12–T17 待实施
**上游产品定义：** `docs/product/accesspilot-product-function-book-v1.1.md`

## 1. 目标

在已完成的 MVP 和 T09–T11 基线上，交付一个用于作品集和面试演示、但产品行为接近真实企业权限入口的 Agent。普通产品界面固定当前身份，能够理解自然语言权限名称、真实流式呈现处理过程、基于证据回答政策问题，并继续完成申请、审批、开通和恢复闭环。

本版本不接入真实 SSO、企业目录或 IAM；所有业务数据继续使用原创虚构内容。

## 2. 当前基线

- T01–T08：申请、风险审查、串行审批、幂等开通、SSE 格式回放、assistant-ui 工作台、运营控制台和固定评测已完成。
- T09：Workspace 后端绑定演示身份已完成。
- T10：身份范围内的可申请权限和有效授权查询已完成。
- T11：七类意图路由、只读工具白名单和基础安全响应已完成。

当前不足：产品界面直接暴露角色切换和模型预算；自然语言权限名称不能落到稳定编码；SSE 只批量回放且聊天整段返回；政策问答和结果卡片未完成。

## 3. 范围与顺序

1. T12：产品身份与 Demo 控制面分层；
2. T13：权限名称实体解析；
3. T14：真实流式响应与 Workspace SSE；
4. T15：政策问答与提示词攻击防护；
5. T16：权限、政策和状态业务卡片；
6. T17：产品化评测、指标与作品集证据。

## 4. 功能需求

### FR-01 产品身份与 Demo 分层

- 产品头部只显示后端当前身份，不提供角色切换。
- 作品集产品身份由 `ACCESSPILOT_PRODUCT_ACTOR_ID` 配置，默认 `EMP-001`；客户端和旧 Workspace 演示覆盖不能修改它。
- “待我审批”等入口按后端职责显示，用户不能冒充其他审批人。
- 角色选择、Workspace 重置、故障注入和模型预算移入演示控制台。
- `ACCESSPILOT_DEMO_MODE_ENABLED` 只控制 Demo 能力是否存在；选择场景后才创建 `demo_session_active` 演示会话，产品表面显示演示标识并提供“返回产品身份”。
- 退出演示会话或关闭 Demo 功能开关时清除或忽略演示身份覆盖与故障模式，恢复产品身份；其他身份的草稿和业务事实不删除、不改绑、不暴露。
- Demo 功能关闭时所有 Demo 控制 API 返回 404；普通产品 API 和事件负载不包含身份控制、故障控制或原始配额字段。
- UI 说明演示控制不代表真实产品权限。

### FR-02 模型预算

- “20 次”是 Workspace 模型调用预算，不是聊天轮数。
- 产品界面、普通产品 API、聊天响应和所有产品事件负载均不得返回原始预算字段；Demo 控制台通过受保护的 Demo API 显示已用、上限、剩余和重试消耗。
- 预算耗尽后，确定性只读查询、历史回放、草稿查看以及已有完整草稿的按钮确认与提交继续可用且不调用模型。
- 新的自然语言草稿抽取返回明确降级提示，不修改草稿，也不继续消费配额。

### FR-03 权限名称解析

- 候选集只来自当前身份可申请权限；后端按稳定编码、名称、系统和受控别名进行规范化精确匹配。
- 受控别名来自随权限目录版本管理的后端固定映射，只能指向对应权限；v1.1 不提供运行时自由编辑入口，未知别名不得命中。
- 规范化只处理大小写、空白和常见分隔符；v1.1 不使用无边界模糊匹配。
- 唯一匹配自动写入稳定 `entitlement_id`。
- 多个匹配返回绑定当前草稿目标字段的类型化候选且不修改草稿；选择时重新校验资格。
- 选择不同权限后旧确认失效；无匹配返回当前可申请权限，模型不能生成未知编码。
- 解析后继续通过资格和期限校验。

### FR-04 当前轮真实流式响应

- `POST /api/chat/messages/stream` 返回 `text/event-stream`，逐步发送意图、工具、草稿、回答增量、完成和错误事件。
- 模型生成文本使用真实 `message.delta`；确定性短回答可直接完成。
- 结构化输出通过严格 Schema 前不修改草稿；每轮只允许一个 `message.completed` 或 `error.recoverable` 终态。
- `message.completed` 包含完整安全回答，并在终态发送前持久化到对话历史与 Workspace 事件。
- 用户取消停止后续生成，不回滚已提交的业务事实；未完成轮次不得产生伪造的完成消息。

### FR-05 Workspace SSE

- `GET /api/events` 按 `Last-Event-ID` 回放持久化事件后保持长连接。
- 支持心跳、断开检测和游标恢复，重连不得重复消息或副作用。
- `message.delta` 不逐片回放；取消时丢弃未完成文本、不持久化半截助手消息，也不回滚已通过业务校验的事实。
- 取消或连接中断持久化 `turn.interrupted`，刷新后显示可重试的中断状态；已完成轮次恢复完整 `message.completed`。
- 活动流与当前轮事件使用稳定 `turn_id`、`tool_call_id` 和 `request_id` 关联。

### FR-06 政策问答与安全

- 基本政策确定性返回完整 8 条主题。
- 具体问题只引用本轮 RAG 证据，展示编号、标题和正文。
- 自审批问题引用 `POL-006` 并明确禁止。
- 政策 API 返回 `grounded`、`insufficient_evidence`、`retrieval_unavailable` 三种状态；前端必须按状态映射为不同卡片、提示和下一步。
- 稳定拒绝系统提示词、密钥、隐藏推理、内部配置和越权请求。
- 复合攻击指有效业务请求同时夹带系统提示词索取、密钥索取、身份覆盖、自审批或工具参数注入；系统可继续安全业务意图，但不泄露内部内容、不采用攻击参数、不越过任何写操作守卫。
- 自动化安全矩阵至少覆盖“权限申请+系统提示词索取”“政策查询+密钥索取”“自审批+身份覆盖”“有效意图+未知工具参数”。

### FR-07 业务卡片与时间线

- 权限卡片区分可申请、已拥有、审批中、即将过期和已过期。
- 政策卡片展示编号、标题和正文依据，并区分证据不足与检索服务不可用。
- 申请时间线区分草稿、提交、风险审查、两级审批、开通和恢复。
- 卡片来自类型化 API，不从模型自由文本推断业务事实。

### FR-08 上下文与记忆

- 线程保存最近消息、摘要、当前意图、草稿、活动申请和待确认操作。
- 身份、资格、授权、审批和政策每次从事实源读取。
- 审计事件不整体注入模型上下文。
- 本版本不自动写入跨会话长期偏好。

## 5. Agent 与工具边界

只读工具包括员工上下文、可申请权限、有效授权、权限名称解析、政策目录、政策检索和申请状态。服务端执行器注入身份、严格校验参数并限制返回字段。

申请提交、人工审批、IAM 开通和恢复继续由显式业务 API 与确定性服务负责，不进入聊天模型工具白名单。

## 6. 流式事件契约

```text
turn.started
intent.detected
tool.started
tool.completed
draft.updated
message.delta
message.completed
business.status
turn.interrupted
error.recoverable
```

每个事件包含稳定 `turn_id`，工具和业务事件可带 `tool_call_id` 或 `request_id`。浏览器只消费安全白名单字段，不返回隐藏推理、系统提示词、密钥、请求头或原始异常栈。

## 7. 产品体验要求

- 顶部展示当前员工，不显示角色下拉和“17/20 次”。
- Demo 控制台独立、可收起、明确标注演示属性。
- 核心页面每次只有一个主操作，状态、证据和下一步贴近业务。
- 覆盖 1440×900、1024×768 和 390×844。
- 加载、空结果、歧义、证据不足、超限、断线、取消和恢复有明确反馈。
- 遵循现有设计语言卡和 `prefers-reduced-motion`。

## 8. 非功能要求

- 后端测试、Ruff、MyPy、Alembic、前端测试、ESLint、TypeScript 和构建通过。
- 首事件、首 token 和完成时间可测量，但不预设虚构目标值。
- SSE 重连无重复消息和副作用。
- 模型调用受 Workspace 预算保护，只读工具优先且可降级。
- 密钥只存在本地后端 `.env` 或生产密钥管理服务。

## 9. 验收场景

1. 产品头部固定显示服务端产品身份，普通界面与产品 API 无角色控制、故障控制和原始模型预算。
2. Demo 控制台可以显式进入和退出虚构场景；退出演示会话或关闭 Demo 功能后控制 API 返回 404、身份恢复产品配置，其他身份业务事实不改绑或暴露。
3. “帮我申请仪表盘查看”通过受控别名唯一解析为当前身份可申请权限编码，并继续询问期限或理由。
4. 歧义名称返回绑定当前目标字段的候选且不修改草稿；选择时重新校验资格并使过期确认失效；未知名称展示当前可申请权限。
5. 当前轮依次产生意图、工具、回答和唯一终态事件，模型文本以真实 delta 到达，完整回答先持久化再完成。
6. SSE 断线按游标恢复，不重复消息、草稿或副作用；刷新不回放 delta，但恢复完整最终回答或 `turn.interrupted`，不显示半截助手消息。
7. “我能申请什么”和“我现在有什么”分别返回资格目录与真实 `AccessGrant`。
8. 基本政策返回完整 8 条主题；具体问题返回本轮检索证据，并区分证据不足与检索服务不可用。
9. 自审批问题明确拒绝并引用 `POL-006`。
10. 提示词攻击和复合攻击不泄露内部内容、不触发写操作。
11. 申请、审批、开通和恢复继续遵守确认、顺序、越权和幂等守卫。
12. 固定评测、全量检查和目标尺寸浏览器验收通过。

## 10. 非目标

- 真实 SSO、OIDC、LDAP、企业通讯录或 IAM；
- 允许普通用户切换或冒充真实身份；
- 通用聊天、联网搜索或权限领域外问答；
- 模型直接审批、开通或绕过业务守卫；
- 自动学习敏感长期记忆；
- 伪造指标、未经验证修改简历；
- 未经确认推送、合并或部署。

## 11. 迁移与回滚

- 保留 T09–T11 已验证接口，按 Ticket 增量迁移前端。
- 新流式接口上线前保留旧 JSON 对话接口作为回滚路径。
- Demo 控制默认只在本地启用。
- 数据库迁移不删除申请、审批、授权或审计事实。
- 每张 Ticket 独立验证并只做本地提交。
