# AccessPilot 学习使命：掌握 AI 应用全栈开发

## Why
通过亲手完成一个可演示、可解释的企业权限申请 Agent，建立从领域建模、Agent 编排到前后端交付的真实项目能力，用于 AI 应用全栈岗位求职与面试。

## Success looks like
- 能独立解释并实现模型结构化输出、确认守卫、审批顺序和幂等开通
- 能把 LangGraph、FastAPI、PostgreSQL 与 React 串成可运行的 MVP
- 能用测试和真实运行证据说明系统边界与失败恢复方式

## Constraints
- 学习者编写核心业务代码，Agent 负责教学、测试、API 胶水、排错和验证
- 每次只讲一个小概念，先理解再编码
- 所有业务数据保持原创虚构，密钥只保存在本地环境
- Day 7 暂停在结构化输出校验通过处；先用最小权限申请检查器补齐 Python 变量、函数、判断与返回值

## Out of scope
- 接入任何真实企业内部系统、账号或数据
- 在 MVP 阶段追求生产级 IAM 集成
- 在 Python 基础尚未形成前继续堆叠 DeepSeek、LangGraph 或网络适配器语法
