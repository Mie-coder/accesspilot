# AccessPilot 教学资源

## Knowledge

- [Python 官方教程：入门介绍](https://docs.python.org/3/tutorial/introduction.html)
  官方变量、数字、字符串和列表入门。用于最小权限申请检查器的基础语法学习。
- [Python 官方教程：控制流](https://docs.python.org/3/tutorial/controlflow.html)
  官方 `if`、函数与循环教程。等学习者理解变量后再逐步使用。
- [DeepSeek API：首次调用](https://api-docs.deepseek.com/)
  官方 API 入口、服务端密钥、Base URL 和 Python 调用方式。用于实现 DeepSeek 适配器。
- [DeepSeek API：JSON Output](https://api-docs.deepseek.com/guides/json_mode/)
  官方结构化 JSON 输出约束。用于设置 `response_format`、Prompt 示例和处理空输出。
- [Pydantic 文档](https://docs.pydantic.dev/latest/)
  Python 数据校验的官方文档。用于 `ParsedReply` Schema、严格布尔值和校验错误。

## Wisdom (Communities)

- [DeepSeek API GitHub Discussions](https://github.com/deepseek-ai)
  用于核对 SDK 兼容性、错误行为和社区复现案例；项目决策仍以官方文档和本地测试为准。
