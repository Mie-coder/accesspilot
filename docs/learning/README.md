# AccessPilot 学习资料

本目录集中保存项目教学和复盘材料，与可运行产品代码分开。

- `MISSION.md`：学习目标与动机。
- `RESOURCES.md`：可信学习资料。
- `NOTES.md`：教学偏好和临时笔记。
- `GLOSSARY.md`：学习术语表。
- `learning-records/`：跨课程学习记录。
- `lessons/`：可独立打开的 HTML 小课。
- `reference/`：复习用速查资料。
- `assets/`：课程共享样式和组件。
- `day-06/`：Day 6 的课程复盘与配图。

以后使用 `$teach` 时，将 `docs/learning` 作为教学 Workspace。项目根目录只保留产品、构建、部署和协作入口。
