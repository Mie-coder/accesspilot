# 呆咩：AccessPilot 长期配图角色规范

呆咩是 AccessPilot 学习记录和公众号配图里的固定原创主角。以后使用“小黑正文配图”方式生成时，用呆咩替代默认角色。

## 不可变的人设

- 蓝色圆润连体兜帽轮廓，暖米白色（不使用纯白）椭圆脸。
- 两侧顶部是浅米色卷羊角，角下有小羊耳；不是猫耳。
- 大圆黑眼、很小的鼻口，表情安静、认真、有一点呆。
- 有两只短短的暖米白色手，能拿夹板、转机器、按铃和搬运卡片；短脚、羊角、羊耳和小圆尾也统一为同一暖米白色。
- 蓝色身体侧边有一个小橙色布标。

## 画面气质

- 白底、黑色手绘线稿、蓝色填充，少量红橙蓝中文批注。
- 呆咩必须承担画面的核心动作，不能只站在旁边。
- 维持圆润、呆萌但不幼稚的比例；避免画成猫或照搬任何现成游戏角色。
